# MET Police PRC — ERLC Roleplay Website

This website is connected to the Supabase project supplied in the build.

## Files
- index.html — login
- dashboard.html — PRC dashboard
- css/style.css — styling
- js/supabase.js — Supabase connection
- js/auth.js — login
- js/prc.js — dashboard/database/realtime logic

## Deployment
Upload the whole folder to GitHub Pages, Cloudflare Pages, Netlify, or another static web host.

## Important
The Supabase publishable key is intended for client-side use. Never replace it with a service-role or secret key.

This is a fictional ERLC/UKBP roleplay system and is not an official Metropolitan Police database.
